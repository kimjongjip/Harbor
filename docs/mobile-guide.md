# Harbor Mobile 사용 안내

## 1.13 빠른 설정과 화면 변경

호스트 PC 상단 연결 아이콘에서 **Tailscale 설치 → 로그인하기 → 저장하고 연결 설정 → 휴대폰 연결 링크 만들기** 순서로 진행한다. 설치·공식 로그인 상태를 같은 화면에서 확인하고 주소도 자동으로 채운다. Windows 승인과 공식 계정 인증은 사용자가 완료한다. [설치·로그인과 다른 PC 연결 상세](desktop-ide-guide.md).

모바일 하단은 **세션·터미널·설정**만 남긴다. 연구실·별도 받은함·별도 대화 화면은 없으며, 승인·질문은 해당 세션의 터미널 위에서 처리한다. 위로 스크롤하면 이전 질문과 답변을 이어 읽는다. 다른 기기가 입력 중이면 읽기 전용으로 표시되며 **여기서 제어**로 넘겨받는다. 세션을 보기만 하거나 미리 읽는 동안에는 입력 제어권을 취득하지 않는다. 완료 알림·첨부·전송은 유지된다.

Harbor는 개인용 iPhone 홈 화면 웹앱(PWA)을 제공한다. 앱스토어 등록이나 Apple 개발자 계정 없이 사용한다. **PC Harbor가 실행 중인 동안** 같은 로컬·SSH 세션을 읽고 입력할 수 있다. 1.12.6부터 iPhone의 VPN 없이 접속하는 Tailscale Funnel과 기존 개인망 Serve 중 선택한다. 휴대폰에서 AI를 별도로 실행하지 않는다.

## VPN 없이 연결하기 · 1.12.6 이상

1. PC Harbor를 1.12.6 이상으로 업데이트하고 작업을 정리한 뒤 다시 실행한다. 실행 중인 옛 백엔드는 Funnel 요청을 차단하므로 휴대폰 새로고침만으로는 전환되지 않는다.
2. **PC에만** [Tailscale](https://tailscale.com/download)을 설치하고 로그인·연결을 켠다. iPhone에는 Tailscale 앱이나 VPN이 필요 없다.
3. PC Harbor 상단 **휴대폰 아이콘 → iPhone · 모바일 연결**에서 **VPN 없이 연결 · Tailscale Funnel**을 선택한다. **PC 주소 확인**으로 HTTPS 주소를 가져온다. 주소를 비워두고 다음 버튼을 눌러도 자동 확인한다.
4. **저장하고 연결 설정**을 누른다. 처음에는 **Tailscale에서 연결 허용** 링크가 나타날 수 있다. 본인 계정에서 허용한 뒤 돌아와 같은 버튼을 다시 누른다. **VPN 없는 연결 경로 설정 완료**를 확인한다. PC 로그인·Funnel 권한·DNS 반영 상태에 따라 실제 휴대폰 접속 확인도 필요하다.
5. **일회용 기기 연결 링크 만들기 → 링크 복사**. 본인 iPhone Safari에서 링크를 열고 기기 이름을 입력해 연결한다. 링크는 10분 동안 한 번만 사용할 수 있다. **기존 등록 기기는 같은 HTTPS 주소라면 재등록 없이 VPN을 끄고 기존 Harbor 주소로 접속한다.**
6. Safari **공유 → 홈 화면에 추가**. 이후 Harbor 아이콘으로 연다. 홈 화면 앱이 다시 등록을 요구하면 PC에서 새 링크를 만들고 앱의 **PC에서 복사한 연결 링크** 입력란에 붙여넣어 연결한다. Safari와 홈 화면 앱의 저장 공간이 다를 수 있으므로 이미 사용한 링크는 재사용하지 않는다.
7. 홈 화면 앱 **설정 → 알림 허용 · 테스트**. iOS 16.4 이상에서 승인·질문 및 AI 응답 완료 알림을 받을 수 있다. 알림 권한은 직접 허용해야 한다. 잠금 화면에는 명령·대화 본문이 표시되지 않는다. [Apple Web Push 안내](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)

Funnel은 무료 플랜에서도 제공하는 공개 HTTPS 중계 기능이다. 별도 고정 공인 IP를 발급하는 기능은 아니다. 개인 `*.ts.net` 주소를 사용하며 대역폭 제한이 있다. **주소 자체는 인터넷에서 접근 가능하지만 Harbor 터미널·대화·입력은 등록 기기 인증이 있어야 한다.** PC Harbor와 PC Tailscale은 계속 실행되어 있어야 한다. [Tailscale Funnel 공식 안내](https://tailscale.com/docs/features/tailscale-funnel)

자동 설정은 현재 PC의 HTTPS 443 루트가 비어 있거나 같은 Harbor 모바일 포트만 가리킬 때 동작한다. 다른 서비스·하위 경로가 있으면 덮어쓰지 않고 안내한다. 공유 설정을 임의로 reset하지 않는다. 직접 설정할 때는 Harbor에서 **Harbor 설정만 저장** 후 PC PowerShell에서 다음을 실행한다.

   ```powershell
   & "$env:ProgramFiles\Tailscale\tailscale.exe" funnel --bg --https=443 http://127.0.0.1:4318
   ```

## 기존 VPN 연결을 사용하거나 돌아가기

**VPN으로 연결 · Tailscale Serve → 저장하고 연결 설정**을 선택한다. PC와 iPhone 모두 Tailscale 설치·로그인·연결이 필요하다. 같은 포트의 Funnel을 Serve로 전환하여 공개 경로를 닫는다. 모바일 창구를 끄는 것과 공개 경로를 개인망으로 전환하는 것은 다르다. [Tailscale Serve 공식 안내](https://tailscale.com/docs/features/tailscale-serve)

직접 설정할 때:

```powershell
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve --bg --https=443 http://127.0.0.1:4318
```

두 방식 모두 **모바일 전용 4318 포트만** 연결한다. PC용 4317/bootstrap을 연결하지 않는다. 모바일 서버는 기본 꺼짐이며 127.0.0.1에서만 수신한다. 기존 설정은 자동으로 공개되지 않으며, 사용자가 PC에서 방식을 선택해 저장한다. iPhone의 VPN On Demand는 자동 VPN 기능으로 Funnel과 별개다.

## 화면 사용

1.15.4부터 로컬 Windows의 Codex·Claude에 **보내기**를 누르면 붙여넣기가 처리된 뒤 Enter를 보낸다. **입력만**과 특수키는 기존대로 동작한다. 전송 도중 다른 기기가 제어권을 가져가거나 대화가 바뀌면 남은 Enter는 보내지 않는다. 오류가 표시되면 PC 입력칸을 확인한 뒤 이어서 입력하며, Harbor가 자동으로 다시 보내지는 않는다. 서버 변경이므로 업데이트 후 PC Harbor를 한 번 다시 실행해야 적용된다.

아이폰에서 입력한 뒤 PC로 돌아오면 터미널 위 **여기서 제어**를 눌러 이어서 입력한다. 다른 기기가 제어 중인 동안 PC에서 누른 키는 전송하거나 대기열에 저장하지 않는다. 제어권 안내·오류는 화면 위 안내로 표시하며 터미널 본문에 쌓지 않는다. PC가 넘겨받으면 휴대폰도 같은 상태를 표시한다.

1.15.2부터 Claude Code의 표준 **Mods 보조 패널**은 모바일에서 기본으로 숨긴다. 캐릭터·위젯을 표시하는 입력창 위 패널과 오른쪽 패널, 별도로 열린 diff 패널이 대상이다. 대화 본문·도구 실행 결과 안의 코드 변경 내용은 계속 표시한다. **Aa → Mods 패널 숨기기**를 해제하면 원래 화면을 볼 수 있으며 설정은 이 휴대폰에 저장한다. PC의 mods 실행·표시나 공유 터미널의 크기를 바꾸지 않는다.

승인·질문 대기 중에는 원래 화면을 표시한다. Claude의 표준 테두리·접기 표시로 확인할 수 없는 사용자 정의 배치와 버전별 새 배치는 내용을 임의로 지우지 않고 그대로 표시한다. 위로 읽던 화면에서 설정을 바꿔도 같은 시점의 원본으로 전환한다. [Claude의 패널과 위젯 구조](https://code.claude.com/docs/en/plugins/mods/interface).

1.12.8부터 세션 목록을 보는 동안 다음에 열 화면 하나를 미리 준비한다. 세션을 터치하거나 키보드로 포커스하면 그 세션을 우선 준비하며, 이미 읽고 있던 결과를 열기 동작에 이어 사용한다. 모든 세션을 계속 내려받지는 않는다. 준비된 화면은 최대 15초 동안 메모리에만 보관하며 앱을 닫거나 새로고침하면 사라진다. **이전 화면 · 최신 내용 확인 중**일 때는 읽기만 가능하며 최신 연결 확인 후 입력이 활성화된다. 빠르게 선택해 준비가 끝나지 않았거나 읽기가 실패해도 기존 실시간 연결로 열린다. PC 백엔드 1.12.8 이상이 필요하다.

1.12.7부터 휴대폰 기본 글꼴을 사용하며 약 6MB의 추가 글꼴을 다운로드하지 않는다. 화면 코드는 압축 전송하고 재사용한다. 한 번 연 앱의 HTML·JS·CSS는 휴대폰에 저장하므로 다음 실행은 네트워크를 기다리지 않고 화면을 띄운다. 새 버전의 화면 파일은 백그라운드에서 준비해 다음 실행·새로고침에 사용한다. **앱 화면이 열리는 것과 서버의 최신 상태 확인은 별개**이며 최초 연결·Funnel 중계 구간에는 시간이 걸릴 수 있다.

세션 전환은 같은 연결을 사용한다. 최근 3개 세션은 실행 중 메모리에서 직전 화면을 먼저 보여주고 **이전 화면 · 최신 내용 확인 중**으로 표시한다. 최신 화면이 도착한 뒤에만 입력할 수 있다. 대화·출력은 휴대폰의 영구 저장소에 캐시하지 않으며 앱을 닫거나 새로고침하면 이 미리보기는 사라진다. 연결 재사용·전송 압축은 PC 백엔드 1.12.7 이상이 필요하다. 화면 파일 교체만으로 실행 중 백엔드까지 바뀌지 않는다.

1.12.2부터 세션을 열면 최신 출력·입력 위치에서 시작한다. 위로 스크롤해 읽는 동안은 새 출력이 와도 자동으로 아래로 이동하지 않으며, **새 출력 · 맨 아래로** 또는 위쪽 ↓ 버튼으로 돌아간다. 화면 복구 시에는 읽던 위치를 유지하고, 새로고침하면 선택한 세션의 최신 화면으로 돌아온다. 휴대폰의 스크롤은 Harbor가 이미 받은 버퍼를 읽으며 CLI의 자체 과거 페이지를 요청하지 않는다.

위쪽 세션 이름을 누르면 목록 화면으로 나가지 않고 다른 세션으로 전환한다. 왼쪽 ‹는 세션 목록으로 돌아가며 서버·세션 검색을 지원한다. 현재 세션의 승인·질문이 있으면 위쪽 안내에서 받은함으로 이동한다. **Aa**에서 글자 크기를 조절하면 이 휴대폰에 설정을 저장한다.

입력창은 작성량에 맞춰 늘어난다. **↑**는 전송, **입력만 붙여넣기**는 Enter 없이 입력한다. **특수키**를 펼치면 Escape·Ctrl+C·방향키·Enter가 보인다. 화면 키보드가 뜨면 하단 메뉴를 접고 입력창을 키보드 위에 유지한다. 같은 페이지에서 세션을 바꾸면 각각의 입력 초안을 유지하지만 새로고침·앱 강제 종료 때는 초안이 사라진다.

1.12.5부터 완료 답변뿐 아니라 작업 중 코드·diff·명령·긴 파일 경로도 휴대폰 폭에 맞게 줄바꿈한다. 긴 가로 구분선은 한 줄로 표시한다. 답변 안의 넓은 표·수식·코드 블록은 해당 영역 안에서 가로로 읽는다. PC의 터미널 크기는 바꾸지 않는다.

위로 읽기 시작하면 현재 출력 화면을 보존한다. AI가 화면을 지우고 다시 그리더라도 읽던 내용은 사라지지 않고, **새 출력 · 맨 아래로**를 누르면 계속 수신 중이던 최신 화면으로 돌아간다. 터미널에서 계속 위로 올리면 받은 버퍼의 이전 출력, 이어서 저장된 질문·답변을 같은 화면에서 불러온다. 터미널 버퍼에 남지 않은 과거 도구 출력까지 복구하는 기능은 아니며, 저장 기록 조회에는 PC 백엔드 1.12.4 이상이 필요하다. 구버전에서는 수집된 완료 답변과 업데이트 안내를 표시한다.

**대화**는 현재 터미널에 연결된 Codex 또는 Claude의 실제 저장 기록을 읽어 **나 → Codex/Claude** 순으로 표시한다. 위로 계속 올리면 이전 질문과 답변을 자동으로 불러오며 새 답변이 와도 읽던 위치를 유지한다. **대화에서 보기**는 해당 답변으로 연결되는 보조 보기다. 파일에 저장되기 전의 진행 출력은 터미널에서 확인한다. 구버전 PC 백엔드에는 질문 조회 기능이 없어 기존 답변만 표시하므로 작업을 정리한 뒤 PC Harbor를 새 버전으로 다시 실행해야 한다. 모바일 새로고침만으로 백엔드까지 바뀌지는 않는다.

- **세션**: PC에 열려 있는 로컬/SSH 터미널을 서버별로 선택한다. PC의 선택 탭은 바뀌지 않는다. 새 터미널·서버 등록·기록 재개는 현재 PC에서 한다.
- **터미널**: 같은 출력과 현재 입력칸을 휴대폰 폭으로 읽는다. **Aa → A−/A+**는 휴대폰 글자 크기만 조절한다. PC 터미널 크기와 tmux 설정은 바뀌지 않는다. 상단 **대화**는 저장된 질문·답변만 모아서 읽는 보조 화면이다. 네이티브 이미지 프로토콜·파일 링크 미리보기는 모바일에서 모두 지원하지 않는다.
- 아래 입력창에 작성하고 **입력만**은 붙여넣기, **보내기 ↵**는 붙여넣기와 Enter를 보낸다. Ctrl+C/Escape/화살표/Enter 버튼은 선택한 실제 터미널에 해당 키를 전송한다. PC와 동시에 입력하면 같은 CLI 입력칸에서 섞일 수 있으므로 한쪽에서 입력한다.
- **사진·파일**은 32MB까지 기존 세션의 임시 첨부 폴더에 올리고 경로를 초안에 넣는다. 파일만 선택해도 자동 전송하지 않는다. CLI의 이미지 인식 여부는 그 CLI와 입력 모드에 따른다. HEIC 등 미지원 형식은 PNG/JPEG로 변환해서 올린다.
- **받은함**: Harbor에 실제로 도착한 승인·질문에 답한다. 클릭은 기존 요청 처리로 전달되며 CLI의 승인 정책을 우회하지 않는다. 로그인·폴더 신뢰 등 받은함에 나타나지 않는 CLI 화면은 터미널을 확인한다.
- **연구실**: 현재 단계·참여자·목표·현재 결과를 보고 참여자 터미널로 이동한다. 연구실 생성·계획 수정·시작·중지는 첫 버전에서 PC가 담당한다.

입력 결과가 불명확하면 초안을 유지하고 자동 재전송하지 않는다. 화면을 확인한 후 다시 보내야 한다. 중복 요청 ID는 한 번만 실행한다. 초안은 앱 메모리에만 있고 앱 강제 종료·새로고침 후 보존되지 않는다. 앱이 백그라운드에서 정리되었을 때도 재접속하면 서버의 현재 화면을 다시 받는다.

## 답변 완료 알림 · 1.12.8 이상

1. PC Harbor를 1.12.8 이상으로 다시 실행하고 휴대폰 화면을 새로고침한다. 기존 작업 중 강제로 PC 앱을 종료하지 않는다.
2. iPhone Safari에서 **공유 → 홈 화면에 추가**한 Harbor 아이콘으로 연다. iOS 16.4 이상이 필요하며 Safari 탭에서의 사용과 홈 화면 앱의 알림 허용은 다르다.
3. 모바일 **설정 → 답변 완료 알림 켜기**를 누르고 iPhone의 알림 요청을 허용한다. **알림: 켜짐**을 확인한다.
4. **테스트 알림 보내기**를 눌러 알림 센터에서 확인한다. 전송 성공 표시는 푸시 서비스의 수락이며 휴대폰에 표시됐다는 보장은 아니다. 표시되지 않으면 iPhone 설정의 Harbor 알림 허용·집중 모드·네트워크를 확인한다.

Codex·Claude가 답변을 마치면 등록한 기기로 알림이 온다. 알림을 누르면 해당 세션을 열며, 잠금 화면에는 답변 내용·파일 경로를 싣지 않는다. 휴대폰에서 다른 앱을 보거나 잠근 상태에서도 Web Push로 받을 수 있다. PC Harbor와 인터넷 연결은 유지되어야 하며 Funnel에서는 휴대폰 VPN이 필요 없다. PC가 꺼진 동안 완료를 감지해 나중에 전송하는 기능은 아니다.

완료 감지는 Harbor에 연결된 Codex 네이티브 런타임과 Claude 훅을 사용한다. 연결되지 않은 일반 셸 출력만 보고 완료를 추측하지 않는다. Codex 실패·중단, Claude 도구 실행·실패, Harbor가 Claude에 후속 작업을 전달해 계속하는 경우는 완료 알림에서 제외한다. 승인·질문은 기존 받은함 알림을 유지한다. 등록이 만료되면 다시 켜도록 안내하며 **알림 끄기**는 이 기기에만 적용된다.

## 해제·오류 확인

- PC 모바일 설정의 기기 **연결 해제**는 해당 기기의 스트림과 이후 요청을 차단한다. 모바일 **설정 → 이 기기 연결 해제**도 가능하다. 등록은 90일 후 만료된다. HTTPS 주소 변경 시 기존 기기는 다시 등록한다.
- 전체 사용을 중단하려면 PC 설정의 **끄기**. 모바일 수신을 중지하며 PC 터미널은 유지한다. Tailscale 경로 설정은 남아 있지만 Harbor에 접근할 수 없다. 전용 공개 경로를 제거하려면 `tailscale funnel --https=443 off`, 개인망 경로는 `tailscale serve --https=443 off`를 사용한다. 해당 HTTPS 설정 전체에 영향을 주므로 다른 서비스가 공유하지 않는지 먼저 확인한다.
- 접속 실패: PC Harbor 버전/실행 상태, PC Tailscale 로그인, 대상 4318, 저장한 HTTPS 주소와 선택한 방식을 확인한다. Serve만 iPhone Tailscale 연결이 필요하다. Funnel 최초 활성화 후 DNS 반영에 시간이 걸릴 수 있다. 모바일 포트 충돌은 PC 설정에 표시되며 PC 터미널은 계속 사용할 수 있다.
- 기기 등록이 안 되면 새 링크로 다시 시도한다. 잘못된 코드의 반복 실패 제한은 1분 후 풀린다. 유효한 일회용 링크는 다른 실패 요청이 많아도 등록할 수 있다. 개인용 등록 기기 모델이며 다중 사용자 권한·계정 관리 기능은 제공하지 않는다.
- PC Harbor 종료·PC 전원 종료·SSH 자체 종료 문제는 모바일 화면으로 해결되지 않는다. 독립 세션 실행 데몬은 [후속 계획](mobile-and-orca-plan.md)의 2단계다. 모바일 구현 때문에 기존 SSH를 tmux로 전환하지 않는다.

## 검증 범위

격리된 로컬 서버와 합성 세션에서 인증·요청·스트림·파일 전송·모바일 크기 브라우저 흐름을 검증한다. Funnel 프록시 헤더를 포함한 HTTP/WS 인증·개인망 복귀·기기 유지와 고정 CLI 인자·설정 충돌·계정 허용·구버전 UI를 별도 검증한다. 실제 사용자 세션에는 테스트 입력을 보내지 않는다. 실제 iPhone Safari 설치, 키보드/사진 선택, LTE/Wi-Fi 전환, 잠금 화면 Push·공개 망 도달은 본인 기기를 연결한 뒤 별도 확인한다. Tailscale 가입·로그인·아이폰 설치를 코드 테스트 완료와 혼동하지 않는다.
